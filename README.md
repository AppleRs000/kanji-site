# かんじ れんしゅう

小学生向けの漢字練習サイトです（静的サイト・サーバー不要）。
学年を選んで、「よみ」「かき」の4択問題を解きます。

## できること
- 学年を選ぶ（データのある学年だけ選べます。いまは3年生）
- 範囲：その学年だけ／1〜その学年のふくしゅう／にがて漢字
- 問題：よみ（ことばの読みを4択）／かき（ひらがな部分に入る漢字を4択）／まぜまぜ
- まちがえた漢字は端末（ブラウザ）に覚えて、次から多めに出題します

## 公開のしかた（GitHub Pages）
1. このフォルダの中身をGitHubのリポジトリに置く
2. Settings → Pages → Branch を `main` / `(root)` にして保存

## ファイル
| ファイル | 役割 |
| --- | --- |
| `index.html` | 画面 |
| `style.css` | 見た目 |
| `app.js` | 出題・採点のしくみ |
| `data-grade3.js` | 3年生の漢字データ（200字） |

## 学年を増やすには
1. `data-grade3.js` をコピーして `data-grade4.js` を作り、`GRADE = 4` にして漢字を書き換える
2. `index.html` の `<script src="data-grade3.js"></script>` の下に `<script src="data-grade4.js"></script>` を足す

データの1行は次の形です。

```js
["運","ウン","はこ(ぶ)",[["運動","うんどう","うん"],["運ぶ","はこぶ","はこ"]]],
// [漢字, 音読み, 訓読み, [[例語, 例語の読み, その漢字にあたる部分の読み], ...]]
```

音・訓が複数あるときは「・」で区切り、ないときは「-」にします。

## 注意
データは下書きです。公開前に、読みと例語を先生の目で確認してください。
