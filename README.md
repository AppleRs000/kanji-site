# かんじ れんしゅう

小学生向けの漢字練習サイトです（静的サイト・サーバー不要）。
学年を選んで、「よみ」「かき」の4択問題を解きます。

## できること
- 学年を選ぶ（データのある学年だけ選べます。1〜6年生、配当漢字1,026字）
- 範囲：その学年だけ／1〜その学年のふくしゅう／にがて漢字
- 問題：よみ（ことばの読みを4択）／かき（ひらがな部分に入る漢字を4択）／りょうほう
- 選んだ学年でまだ習っていない漢字は、ひらがなで表示します（例：2年生を選ぶと「京都」は「京と」）
- まちがえた漢字は端末（ブラウザ）に覚えて、次から多めに出題します

## 公開のしかた（GitHub Pages）
1. このフォルダの中身をGitHubのリポジトリに置く
2. Settings → Pages → Branch を `main` / `(root)` にして保存

## データを直すには
学年ごとのファイル（`data-gradeN.js`）を開いて、該当の行を書き換えます。
例語を足すときは、`[例語, 例語の読み, その漢字にあたる部分の読み]` を行の中に追加します。

データの1行は次の形です。

```js
["運","ウン","はこ(ぶ)",[["運動","うんどう","うん"],["運ぶ","はこぶ","はこ"]]],
// [漢字, 音読み, 訓読み, [[例語, 例語の読み, その漢字にあたる部分の読み], ...]]
```

音・訓が複数あるときは「・」で区切り、ないときは「-」にします。

## 注意
データは下書きです。公開前に、読みと例語を先生の目で確認してください。


## 漢字プリント作成
`print.html` を開くと、A4横の漢字プリント（国語ドリルと同じ縦書き・右から左へ並ぶ）を作成できます。
- 1枚は**縦2段 × 横10列＝最大20問**。21問以上は2枚目以降に続きます（最大100問）
- 上部に **名前・日付・得点** の記入欄つき
- 範囲：学年全体／前学年までの復習／苦手漢字／漢字を個別選択
- 問題：書き／読み／両方（両方のときは上段＝読み、下段＝書き）
- 読み問題は、右に言葉（対象の漢字の右に線）、左に（　）の答えらん
- 書き問題は、ますの左に読み方、ますの前後に送りがな・ほかの字を印字。同じ漢字の練習ます（0〜2つ）つき
- 習っていない漢字は、ひらがなで表示
- 解答：問題のみ／別ページ／問題と同じ紙に（赤字）
- 印刷：A4・横向き・余白なし・倍率100%で「印刷・PDF保存」
- iPhone・iPadのSafariは「横向き」の指定が効かないため、「縦向きの用紙で印刷する」にチェックすると、内容を90度まわして縦向きのA4に印刷します（iPhone・iPadでは最初からチェック済み）。紙を横にして読みます
- 「テスト」を選ぶと、練習ますもうすい字もなく、答えを書くますだけが並びます（5〜20問、「覚えているか」の確認用）
- 「書き順の一覧」をつけると、出した漢字の書き順（1画ずつ増える図）が別のページに付きます（ネットから書き順データを読みこみます）
- 10問以下のときは1段5問になり、ますや字が大きくなります
- 練習ますは0〜4つ。1つ目を「うすい字」にすると、なぞり書きができます
- 読み問題の答えは、下線の漢字の読みだけです（解答にも同じ読みが出ます）

- 「書き順プリント」を選ぶと、問題は出さずに、漢字ごとに「書き順の図＋なぞる練習ます（1つ目はうすい字）」の行が並びます。「漢字を選んで範囲を指定」にすると、選んだ漢字だけ（最大100字）を印刷できます

## オフライン
一度ネットにつないで開くと、クイズ・印刷・書き順のページがネットなしでも開けます（`sw.js`）。書き順データは、`trace.html` の「書き順データをぜんぶ保存する」で、全1,026字を端末に保存できます。保存していない漢字の書き順は、ネットがないと出ません。公開（更新）したあとは、ネットにつないで一度開くと、新しい版に変わります。

## かきじゅん・なぞりがき
`trace.html` で、書き順のアニメーション、うすい字をなぞる練習、見ないで書く練習ができます。
- トップ画面のボタン、または「まちがえた かんじ」の「かきじゅん」から開きます
- 書き順データはネット上（jsDelivr / unpkg）から読みこむので、インターネットにつながっているときに使えます
- データ：@k1low/hanzi-writer-data-jp（chanind版 hanzi-writer-data-jp のフォーク。Arphic Public License / LGPL）、表示：Hanzi Writer（MIT）
- 書けた漢字には ✓ がつきます（この端末のブラウザにだけ記録）

## 苦手漢字ページ（weak.html）
まちがえた漢字を学年別／まちがい回数別に一覧できます。ここから「苦手だけクイズ」「苦手だけ印刷」に進めます。正解すると回数が減り、0になると自動で消えます。「書き出し」で引き継ぎコード（KJ1:…）またはファイル（kanji-nigate.json）を作り、別の端末で「読み込み」すれば記録を移せます（合算されます）。

## クイズの書き順表示
クイズの答えのあとに「書き順を見る」ボタンが出ます。トップの「答えたあとに、書き順を見る」にチェックすると自動で表示します（書き順データを読むのでネットが必要）。

## 印刷の「短文」形式
印刷画面の「もんだいの形」で「短文」を選ぶと、例語ではなく短い文の中の漢字を読む／書く問題になります。例文は `sentences-grade*.js` にあり、Claudeが作った下書きなので、先生の目で確認・修正してください（形式: `window.KANJI_SENT["漢"]=["語","文"]`）。

## マスター率
クイズで同じ漢字に2回つづけて正解すると「マスター」になります（まちがえると0にもどり、にがて漢字にもなります）。`weak.html` の上に学年ごとのマスター率、クイズのトップに選んだ学年のマスター数が出ます。記録は書き出し・読み込みで端末間を移せます（コード形式 `KJ1:` は旧版と互換）。

## 学年まとめテスト（印刷）
`print.html` の「学年まとめテストにする」ボタンで、選んだ学年の全字を1回ずつ出題するテスト（読み・書きまぜ、解答つき）の設定になります。問題数の「ぜんぶ」を選んでも同じことができます。
